# UgnAI Labs Co.

Company site for [UgnAI Labs](https://ugnailabs.co): software that connects people, places, and decisions.

## Stack

- Next.js
- TypeScript
- Tailwind CSS
- shadcn/ui
- Framer Motion
- Lucide

## Develop

```bash
npm install
npm run dev
```

Open [http://localhost:3023](http://localhost:3023).
